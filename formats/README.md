# formats 文件说明

本目录存放格式规范；`pages/` 对应独立页面，`common/` 对应通用格式。

[additional_formats_index.md](additional_formats_index.md) 记录新增规范的资料来源、优先级和工程模块对应关系。

## pages：独立页面规范

| 文件 | 作用和内容 |
| --- | --- |
| [cover_format.md](pages/cover_format.md) | 封面的字段、布局、字体、位置和参考依据。 |
| [originality_format.md](pages/originality_format.md) | 原创性声明的原文、字段、段落和签名布局。 |
| [copyright_format.md](pages/copyright_format.md) | 著作权声明的原文、授权选项和页面排版。 |
| [ai-declaration_format.md](pages/ai-declaration_format.md) | 使用与未使用 AI 工具两种声明的独立版式。 |
| [committee_format.md](pages/committee_format.md) | 答辩委员会名单的字体、列宽、行距和无边框表格。 |
| [abstract_format.md](pages/abstract_format.md) | 中英文摘要的页面、标题、正文和关键词。 |
| [contents_format.md](pages/contents_format.md) | 中英文目录的层级、缩进、点线和页码。 |
| [references_format.md](pages/references_format.md) | 参考文献页面、数字编号、条目排版和样式处理。 |
| [appendix_format.md](pages/appendix_format.md) | 附录位置、标题层级及图表公式编号。 |
| [acknowledgement_format.md](pages/acknowledgement_format.md) | 致谢页面、正文、落款和页眉页码。 |

## common：通用格式规范

| 文件 | 作用和内容 |
| --- | --- |
| [page_layout_format.md](common/page_layout_format.md) | 页面尺寸、页边距、页眉页脚、页码和打印分页。 |
| [body_format.md](common/body_format.md) | 普通正文的对齐、行距、首行缩进和段间距。 |
| [headings_format.md](common/headings_format.md) | 各级标题的编号、对齐、间距和分页。 |
| [figures_tables_format.md](common/figures_tables_format.md) | 图表的位置、编号、标题、说明和交叉引用。 |
| [code_algorithm_format.md](common/code_algorithm_format.md) | 代码与算法的既有用法及尚未明确的规范范围。 |
| [equations_format.md](common/equations_format.md) | 公式布局、右侧编号和交叉引用。 |
| [footnotes_format.md](common/footnotes_format.md) | 脚注的带圈编号、按页重置和脚注区域。 |
