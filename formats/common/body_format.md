# 正文段落版式规范（body_format.md）

## 1. 适用范围

本文件只规定正文普通段落的排版，不规定字体家族、字号或字体映射。

对应工程文件：

- `styles/common/fonts.tex`：如果当前工程在这里设置全文默认行距，只调整行距相关命令。
- 正文段落样式可在 `styles/common/headings.tex` 或工程已有的正文样式定义中实现。
- 不要因为本文件而修改 `styles/common/fonts.tex` 中的字体设置。

## 2. 正文段落

根据官方 Word 模板的“我的正文”样式和 PDF 正文页面：

1. 正文段落采用两端对齐。
2. 正文行距为 1.5 倍。
3. 每个普通正文段落首行缩进约两个汉字宽度。
4. 普通段落不额外增加段前、段后空白；段落之间主要依靠首行缩进和行距区分。
5. 正文段落应自然连续排版，不使用连续空格模拟缩进。

## 3. 首行缩进的提取说明

Word 文件中存在轻微的属性差异：

- “我的正文”样式本身的首行缩进为 420 twips。
- 摘要和正文中的实际段落还存在直接格式覆盖，首行缩进为 480 twips。
- PDF 的视觉效果均接近两个汉字宽度。

因此 LaTeX 实现建议使用 `2em` 作为正文段落首行缩进，而不是机械复刻 Word 中每个段落的零散覆盖值。若当前模板的中文正文基准字号或 `em` 定义不同，应以最终视觉效果为准。

## 4. 行距

- 正文行距：1.5 倍。
- Word “我的正文”样式的 OOXML 行距值为 360 twips，规则为自动行距，对应 1.5 倍。
- 不要把正文改成单倍行距。
- 不要同时使用多个互相冲突的全局行距命令。

## 5. 与其他段落的区分

以下内容不应直接继承普通正文的首行缩进：

- 章、节、小节标题；
- 图题、表题；
- 图表说明；
- 行间公式；
- 目录条目；
- 参考文献条目；
- 页眉页脚。

这些内容分别按各自的 `*_format.md` 文件处理。

## 6. LaTeX 实现要求

- 只修改行距、段落对齐、首行缩进和段落间距。
- 不要在每个章节文件中重复设置 `\parindent` 和 `\baselineskip`。
- 优先在统一的正文样式位置设置，确保摘要和正文是否共用该样式由各自模块决定。
- 不要为了模拟 Word 的段落布局而在正文内容中添加手工空格。

## 7. 验收清单

- [ ] 正文普通段落两端对齐。
- [ ] 正文行距为 1.5 倍。
- [ ] 正文首行缩进约 2em。
- [ ] 段落之间没有不必要的额外空白。
- [ ] 标题、公式、图表、目录、参考文献没有错误继承正文首行缩进。
