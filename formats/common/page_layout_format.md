# 页面版式规范（page_layout_format.md）

## 1. 适用范围

本文件规定论文全局页面尺寸、页边距、页眉页脚、页码体系和前后置部分的分页规则。

对应工程文件：

- `styles/common/base.tex`：纸张、页边距、页面布局宏包。
- `styles/common/headings.tex`：页眉、页脚和页面样式。
- `main.tex`：各论文部分的调用顺序及分页位置。

本文件不重新定义封面、原创性声明、著作权声明、AI 声明和答辩委员会名单的具体内容及版式。

## 2. 页面尺寸与页边距

以官方 Word 模板的 OOXML 页面设置为准，PDF 页面尺寸也与 A4 一致。

| 参数 | 规范值 |
|---|---:|
| 纸张 | A4 |
| 页面方向 | 纵向 |
| 页面宽度 | 210 mm |
| 页面高度 | 297 mm |
| 上边距 | 30.0 mm |
| 下边距 | 25.4 mm |
| 左边距 | 31.7 mm |
| 右边距 | 31.7 mm |
| 页眉距页面顶部 | 20.0 mm |
| 页脚距页面底部 | 17.5 mm |
| 装订线 | 0 mm |

说明：

- Word 内部对应的页面设置约为：上边距 1701 twips、下边距 1440 twips、左右边距各 1797 twips、页眉 1134 twips、页脚 992 twips。
- 左右边距相同；当前样例没有显示奇偶页镜像页边距或额外装订线。
- 不要把开源本科模板中“上、左至少 25 mm，下、右至少 20 mm”的概括性要求替代上述研究生 Word 模板的具体数值。

## 3. 页码体系

### 3.1 封面与声明部分

- 封面不显示页码。
- 原创性声明、著作权使用声明所在页面不显示页码。
- 若打印版分页产生空白页，空白页不显示页码。

### 3.2 前置部分

从中文摘要开始使用大写罗马数字，单独连续编号：

| 页面 | 页码 |
|---|---|
| 中文摘要 | I |
| 英文摘要 | II |
| 中文目录 | III |
| 英文目录 | IV |

前置部分页码位于页面底部居中。前置部分页面不显示正文页眉。

### 3.3 正文及后置部分

- 正文第一章从阿拉伯数字 `1` 开始。
- 正文、参考文献、附录（如有）、致谢使用同一套阿拉伯数字连续编号。
- 页码位于页面底部居中。
- 参考文献和致谢不得重新从 1 开始编号。

官方 PDF 示例中，正文页为 1、2，参考文献页为 3，致谢页为 4。

## 4. 页眉

前置部分不显示正文页眉。正文及后置部分采用奇偶页不同的页眉：

- **奇数页**：显示当前章节或当前独立部分的标题。例如正文页显示“第一章 序论”，参考文献页显示“参考文献”。
- **偶数页**：显示论文题目。
- 页眉文字居中。
- 页眉下方设置一条横线，横线沿正文版心宽度延伸。
- 页眉内容应随章节或独立部分自动更新，不应在每页手动写死。

实现时优先使用 `fancyhdr` 或当前工程已有的页眉机制，正确区分 odd/even page style。不要让摘要、目录页面误继承正文页眉。

## 5. 页脚

- 页脚只放页码。
- 页码水平居中。
- 前置部分使用大写罗马数字；正文和后置部分使用阿拉伯数字。
- 不要在页脚额外添加论文题目、章节标题或装饰文字。

## 6. 分页与打印版空白页

官方 PDF 共 12 页：声明部分之后出现一张无内容、无页码的空白页，随后中文摘要从下一张奇数页开始。

开源 `example.tex` 中的 `\print` 选项注释明确说明：打印版会在必要的偶数页插入空白页，使下一部分从奇数页开始。因此应按以下方式处理：

- 电子版：不应为了凑奇偶页而无条件插入空白页。
- 打印版：沿用工程已有的 `\print` 选项；只有在需要使下一部分从奇数页开始时才插入空白页。
- 自动插入的空白页应保持真正空白，不显示页眉、页脚和页码。
- 不要在 `main.tex` 中硬编码固定数量的空白页。

摘要、目录、正文主章节、参考文献、致谢等独立部分应从新页开始。是否需要进一步强制从奇数页开始，取决于当前电子版/打印版选项。

## 7. LaTeX 实现位置

- 在 `styles/common/base.tex` 中设置 `geometry`。
- 在 `styles/common/headings.tex` 中设置奇偶页页眉、页眉横线、页脚页码和空白页样式。
- 在 `main.tex` 中保留合理的前置部分、正文和后置部分顺序。
- 不要在每个内容模块中重复设置整套 geometry 参数。

## 8. 验收清单

- [ ] 页面为 A4 纵向。
- [ ] 四边页边距与表格中的数值一致。
- [ ] 页眉、页脚距页面边缘的位置正确。
- [ ] 封面和声明部分不显示页码。
- [ ] 中文摘要开始为罗马数字 I，英文摘要为 II。
- [ ] 中文、英文目录页码分别为 III、IV。
- [ ] 正文从阿拉伯数字 1 开始。
- [ ] 参考文献、附录、致谢页码连续。
- [ ] 奇数页页眉为当前章节/部分标题，偶数页页眉为论文题目。
- [ ] 页眉下方有横线，页码居中。
- [ ] 打印版只在必要时插入无页眉页脚的空白页。
