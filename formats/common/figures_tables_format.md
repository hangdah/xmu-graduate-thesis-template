# 图片与表格版式规范（figures_tables_format.md）

## 1. 适用范围

对应工程文件：`styles/common/floats.tex`。

本文件规定图片、表格的编号、位置、标题和说明文字，不规定字体家族或字号。

## 2. 编号规则

图片和表格均按章节编号：

- 第一章第一张图：`图 1.1`。
- 第一章第二张图：`图 1.2`。
- 第一章第一张表：`表 1.1`。
- 第二章第一张图：`图 2.1`。
- 第二章第一张表：`表 2.1`。

每章开始时分别重置图片和表格计数器。编号应由 LaTeX 自动生成，不要在正文中手工写死编号。

开源 `example.tex` 明确说明图片和表格均按照“章节号-序号”编号；官方 PDF 的图 1.1、表 1.1 与该规则一致。

## 3. 图片

- 图片在版心内水平居中。
- 图片标题位于图片下方。
- 图片标题水平居中。
- 图片标题采用“图 + 章节编号 + 图片名称”的形式。
- 图片说明或资料来源（如有）放在图片标题附近的下方说明区域，使用独立的图表说明样式。
- 图片与正文之间应保留合理间距，不得与正文文字重叠。
- 图片应按原始比例缩放，不得为了填满版心而拉伸变形。
- 图片宽度应受版心宽度限制；不要照搬 `example.tex` 中单张示例图片的 `12em` 固定尺寸。

Word 的“图标题”样式居中，首行缩进为 0，段后间距为 320 twips，即 16 pt。PDF 中图题确实位于图下方并居中。

## 4. 表格

- 表格整体水平居中。
- 表格标题位于表格上方。
- 表格标题水平居中。
- 表格标题采用“表 + 章节编号 + 表格名称”的形式。
- 表格内容应保持在版心范围内；过宽表格应通过合理调整列宽、换行或横向页面等方式处理，不得直接溢出版心。
- 表格中应有清晰的行列分隔。

官方 PDF 的表 1.1 使用了网格状分隔线，既有横向分隔线，也有列分隔线。开源 `example.tex` 也使用了带竖线和 `\hline` 的表格示例。因此不要未经确认就把所有表格强制改成完全没有竖线的 `booktabs` 风格。

Word 的“表标题”样式居中、首行缩进为 0，段前间距为 320 twips，即 16 pt。

## 5. 图表说明与资料来源

官方 Word 中存在独立的“图表说明”样式，且明确提示表格和图下的说明文字使用该样式。

- 图表说明放在对应图或表的下方。
- 说明文字与图表主体、标题区分开。
- 说明文字通常以“注：”开头。
- 资料来源（如有）也应放在图表下方的说明区域。
- 不要将说明文字错误地放进图题或表题中。
- Word 中该样式有独立段后间距；具体字体和字号不在本次范围内。

## 6. LaTeX 环境建议

- 图片使用 `figure` 环境。
- 表格使用 `table` 环境。
- 图片内部使用 `\centering`。
- 表格内部使用 `\centering`。
- 图题通过 `\caption` 放在图片之后。
- 表题通过 `\caption` 放在表格之前。
- `\label` 紧跟对应的 `\caption`，确保交叉引用编号正确。
- 浮动体位置可采用合理的 `[!htbp]` 等选项，允许 LaTeX 在页面中寻找合适位置，不要对所有图表使用强制绝对定位。

## 7. 交叉引用

正文引用图片和表格时使用 `\ref` 或工程已经封装的引用命令，不要手动输入编号。

示例：

```latex
如图~\ref{fig:example} 所示。
如表~\ref{tab:example} 所示。
```

## 8. 验收清单

- [ ] 图片、表格分别按章节编号。
- [ ] 图片居中，图题位于图片下方并居中。
- [ ] 表格居中，表题位于表格上方并居中。
- [ ] 图题、表题编号由 LaTeX 自动生成。
- [ ] 图表说明位于图表下方。
- [ ] 表格线条清晰，保留必要的横线和列分隔。
- [ ] 图片不变形、不超出版心。
- [ ] `\label` 和 `\ref` 的引用结果正确。
