# 公式版式与编号规范（equations_format.md）

## 1. 适用范围

对应工程文件：`styles/common/floats.tex`。

本文件规定行间公式、公式编号、编号位置和交叉引用，不规定数学字体或公式字号。

## 2. 公式编号

公式按章节编号：

- 第一章第一个编号公式：`(1.1)`。
- 第一章第二个编号公式：`(1.2)`。
- 第二章第一个编号公式：`(2.1)`。

编号格式为圆括号包围的“章节号.公式序号”。每章开始时重置公式计数器。

官方 PDF 第 10 页显示公式编号 `(1.1)`；开源 `example.tex` 使用 `equation` 环境，并说明公式可通过 `label` 和 `ref` 引用。

## 3. 公式位置与编号对齐

官方 Word 的“公式”段落样式定义了一个靠近正文右边界的右对齐制表位；PDF 中公式编号位于行末右侧。

排版要求：

- 公式主体与编号处于同一行。
- 公式编号单独靠右对齐。
- 不要把公式主体和编号写成一个普通居中字符串。
- 公式主体应在正文版心内排布，不得超出版心。
- 对齐公式组应保持等号或其他关系符号对齐。

PDF 示例中的公式主体从正文左侧缩进区域开始，编号 `(1.1)` 位于右侧；因此不要无依据地强制把所有公式主体放在页面几何中心。

## 4. 行间公式与行内公式

- 行内公式嵌入正文段落，不单独编号。
- 需要编号的行间公式使用独立公式环境。
- 不需要编号的行间公式使用无编号公式环境。
- 公式上下应保留适当空白，但不要插入多余空白段落。
- 多行推导应使用 `align` 等对齐环境，不要依靠手工空格对齐。

## 5. 编号与引用

- 公式编号由计数器自动生成。
- 使用 `\label{eq:...}` 设置标签。
- 使用 `\ref{eq:...}` 引用公式编号。
- 不得在公式环境中手工输入固定的 `(1.1)`，以免章节变化后编号错误。

示例：

```latex
如式~\ref{eq:turning-point} 所示：

\begin{equation}
  Y = -\frac{\beta_1}{2\beta_2}
  \label{eq:turning-point}
\end{equation}
```

## 6. 附录公式

开源 `example.tex` 的附录说明指出，附录中的编号以字母 A 开头。可据此将附录公式编号设计为 ` (A.1) `、` (A.2) ` 等。

但官方研究生 Word/PDF 示例没有附录公式页面，因此该规则属于开源模板提供的实现参考，不是本次官方研究生 PDF 已验证的规则。若当前工程已经有附录计数器，应先检查并保留合理实现。

## 7. LaTeX 实现要求

- 公式编号规则集中放在 `styles/common/floats.tex` 或当前工程的统一编号配置中。
- 不要在 `main.tex` 或章节文件中重复定义公式编号格式。
- 检查公式编号与章节编号的关联。
- 检查编号右对齐，不要与公式主体挤在一起。
- 不要修改公式字体配置。

## 8. 验收清单

- [ ] 公式编号形如 `(1.1)`。
- [ ] 每章公式编号重新从 1 开始。
- [ ] 公式编号右对齐。
- [ ] 公式主体未被强制错误居中。
- [ ] 行内公式不显示编号。
- [ ] `\label`、`\ref` 正常工作。
- [ ] 附录公式（如有）使用 A 前缀，且与正文编号分开。
