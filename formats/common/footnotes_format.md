# 脚注版式规范（footnotes_format.md）

## 1. 适用范围

对应工程文件：`styles/common/footnotes.tex`。

本文件只规定脚注编号、编号重置、标记位置和脚注区域，不规定字体家族或字号。

## 2. 脚注编号形式

官方 Word 模板的各节 `footnotePr` 设置为：

- 编号格式：`decimalEnclosedCircleChinese`，即中文带圈数字形式，视觉上对应 `①`、`②`、`③` 等。
- 编号重置方式：`eachPage`，即每页重新从第一个脚注编号开始。
- 脚注标记采用上标形式。

因此，不应使用全文连续递增的普通阿拉伯数字脚注编号替代该规则。

## 3. 脚注位置与正文区域

- 脚注内容放在对应页面底部。
- 脚注与正文之间应保留脚注分隔区域。
- 脚注正文左对齐。
- 脚注不应进入正文段落的首行缩进逻辑。
- 同一页多个脚注按出现顺序编号。
- 翻页后编号重新开始。

Word 文件中没有实际脚注条目，PDF 示例也没有显示脚注，因此分隔线的具体长度、粗细和脚注与页底的精确距离无法从本次材料确认。不要自行编造这些数值。

## 4. 开源模板中的脚注用法

开源 `example.tex` 使用标准 `\footnote{...}` 命令展示正文脚注用法。当前工程应继续允许在正文中直接使用 `\footnote`，由 `styles/common/footnotes.tex` 统一控制编号和显示样式。

## 5. LaTeX 实现建议

请检查当前 `styles/common/footnotes.tex` 已有的以下设置：

- `\thefootnote`
- `\thempfootnote`
- `\footnotesize`
- `\footnoterule`
- `\footnotesep`
- `\deffootnote`

建议：

1. 使用带圈数字作为普通脚注标记。
2. 使用能够按页重置计数器的机制，例如 `perpage` 宏包的 `\MakePerPage{footnote}`，但必须先检查当前宏包加载情况，避免重复加载或冲突。
3. 脚注标记保持上标。
4. 脚注内容置于页面底部。
5. 保留脚注分隔线，但在没有官方视觉依据时不要擅自指定线长、线粗。
6. 如果脚注数量超过常见带圈数字字符范围，需设置稳定的回退方式，避免编号缺字。

## 6. 验收清单

- [ ] 脚注标记为带圈数字。
- [ ] 脚注标记为上标。
- [ ] 同一页内按顺序编号。
- [ ] 新页面脚注重新从 ① 开始。
- [ ] 脚注位于页面底部。
- [ ] 脚注与正文之间有分隔区域。
- [ ] 脚注设置不影响正文页码、页眉和正文行距。
