# 代码与算法版式规范（code_algorithm_format.md）

## 1. 适用范围

对应工程文件：`styles/common/floats.tex`。

**本次官方研究生 Word/PDF 模板没有提供代码块或算法环境的实际排版示例。** 因此本文件只记录开源 `example.tex` 中能确认的用法，不推断研究生论文的字号、边框、行距、行号或算法标题样式。

## 2. 开源模板中的示例

`example.tex` 展示了两种内容：

1. 使用 `verbatim` 环境展示普通代码。
2. 使用算法环境展示伪代码，并通过 `\caption` 和 `\label` 生成算法标题及交叉引用。

开源示例还提示：如需代码高亮、自动换行、行号和自定义颜色，可考虑使用 `listings` 宏包。

## 3. 本次不能确认的项目

官方 Word/PDF 未提供相应页面，因此以下规则无法确认：

- 代码块是否需要边框或背景；
- 代码是否需要行号；
- 代码行距和段间距；
- 代码字体、字号；
- 算法标题的位置；
- 算法是否按章节编号；
- 算法是否进入目录或独立清单。

不要把开源本科模板中的某种算法环境直接认定为研究生官方规范。

## 4. Codex 修改要求

- 先检查当前 `styles/common/floats.tex` 的代码和算法定义。
- 若现有实现可以正常编译且没有与官方已确认格式冲突，优先保留。
- 不要仅为了“看起来更像论文”而擅自增加背景色、边框、行号或额外标题。
- 不要改变普通正文行距、字体配置或全局页面边距来适配代码块。
- 如需调整，必须将其作为“开源模板示例沿用”而非“官方研究生格式要求”，并在修改报告中说明。

## 5. 验收清单

- [ ] `verbatim` 或现有代码环境能够正常编译。
- [ ] 算法环境能够正常编译。
- [ ] 算法标题和 `\label`、`\ref` 正常工作（若当前工程启用）。
- [ ] 代码或算法不会溢出版心。
- [ ] 未擅自引入缺乏官方依据的装饰和编号规则。
