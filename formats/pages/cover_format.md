# 厦门大学研究生学位论文封面格式规范（`cover_format.md`）

> 本文件记录 LaTeX 模板中**学位论文封面（degree）**的参考规范和当前实现，对应 `styles/pages/cover.tex`。  
> 官方参考数据沿用此前从《附件1.厦门大学研究生学位论文封面格式.docx》及其 PDF 版本提取的记录；当前项目未包含该 DOCX 原文件。  
> 当前实现按用户要求使用 `figures/xmu-logo-text.jpg` 高清校名图片，并通过标签字间距使个人信息四行的冒号对齐。  
> Word 排版属性、官方 PDF 可见坐标、LaTeX 源码定位参数分别记录，不混为一谈。源码参数不代表最终 PDF 已通过视觉校准。  

------------------------------------------------------------------------

## 1. 适用范围与文件说明

### 1.1 适用范围

本规范只约束**学位论文封面**，即当前模板中的：

``` latex
\thesiscover{degree}
```

不适用于实践成果总结报告封面。官方学位论文封面文件没有给出实践成果总结报告封面的完整排版规范，因此：

- 修改 `degree` 模式时，必须按本文件执行。
- 不得将本文件中的标题、作者信息结构和坐标直接套用到 `practice` 模式。
- `practice`
  模式应继续依据学校提供的《实践成果总结报告封面格式》单独制定规范。

### 1.2 参考文件的页面结构

官方 PDF 共 2 页：

- **第 1
  页**：带箭头和文字标注的封面排版说明图。箭头、字号说明、括号注释均为格式说明，不属于最终封面内容。
- **第 2
  页**：四种实际封面样例，分别对应人文社科博士、理工医科博士、人文社科硕士、理工医科硕士。

DOCX 中也包含上述内容。DOCX
的第一页并不是一张可直接作为背景使用的封面图片，而是由普通段落、校名图片、浮动标注对象等共同组成的格式说明页。

### 1.3 结构分析结论

对 DOCX 的 `word/document.xml` 检查结果：

| 项目                           |  结果   | 说明                                       |
|:-------------------------------|:-------:|:-------------------------------------------|
| 页面                           | A4 纵向 | 单节页面设置                               |
| Word 表格 `w:tbl`              |  0 个   | 个人信息不是 Word 表格                     |
| 文本框内容节点 `w:txbxContent` |  18 个  | 主要用于第一页的格式标注，不应当作封面正文 |
| 浮动对象锚点 `wp:anchor`       |  23 个  | 包含格式标注对象和图片等                   |
| 内嵌图片对象 `wp:inline`       |  0 个   | 校名图片使用浮动定位                       |

**重要纠正：** DOCX
中存在文本框和浮动对象，并不代表封面正文全部由文本框组成。个人信息区域的四行正文实际是四个独立段落，没有使用表格。第一页大量箭头和字体说明是标注对象，不能复制到最终封面。

以下参数来自 DOCX 的 Section Properties（页面节属性）。

| 参数     | Word 原始值 | LaTeX 目标值 |
|:---------|:-----------:|:------------:|
| 纸张宽度 |  8.2681 in  |    210 mm    |
| 纸张高度 | 11.6931 in  |    297 mm    |
| 上边距   |   1.00 in   |   25.4 mm    |
| 下边距   |   1.00 in   |   25.4 mm    |
| 左边距   |   1.25 in   |   31.75 mm   |
| 右边距   |   1.25 in   |   31.75 mm   |
| 页面方向 |  Portrait   |     纵向     |

### 2.1 坐标约定

本规范中的 PDF 测量坐标统一采用：

- 原点：页面左上角。
- X 轴：向右为正。
- Y 轴：向下为正。
- 单位：mm。
- 页面尺寸：210 mm × 297 mm。

**PDF 可见坐标的含义：** 下文的文字 X/Y 是 PDF
中可见文字外接框的左上角，不是 Word 段落基线，也不是 LaTeX
节点的基线。图片坐标是图片可见边界的位置。

因此，LaTeX 中不能直接把可见文字的 Y
值当作基线坐标。应以这些值为视觉目标，编译后渲染
PDF，再根据实际字形边界校准。

当前实现使用 TikZ 的 `current page.north west` 作为页面原点，文字节点采用
`anchor=north west`、零内外边距和 `minipage[t]`。节点顶部按首行文字盒高度换算到基线，
并不是直接把表中的 Y 值当成基线。文字盒边界与可见字形边界仍可能有差异，不能将源码定位值视为已完成的最终 PDF 测量值。

### 2.2 页面边距与元素位置的关系

- 左上角基本信息从页面左边缘约 31.76 mm 处开始，与左页边距基本重合。
- 页面居中元素以页面水平中心 `x = 105 mm` 为对齐基准。
- 个人信息区域从页面左边缘约 72.24 mm 处开始。
- 底部日期在页面水平居中位置。

`\xmu@degreecover` 使用 `\newgeometry` 单独设置本页四个页边距，结束时通过
`\restoregeometry` 恢复原设置。居中文字块从 `x = 31.75 mm` 开始、宽 `146.5 mm`，
中心为 `105 mm`；校名图片沿用参考位置，中心约为 `105.28 mm`。

## 3. 封面内容顺序与层级

学位论文封面正文从上至下应按以下顺序排布：

1.  学校编码
2.  学号
3.  厦门大学校名图片
4.  学位名称：博士学位论文 / 硕士学位论文
5.  学位类别：学术学位 / 专业学位
6.  中文论文题目
7.  英文论文题目
8.  作者姓名
9.  指导教师姓名
10. 专业名称
11. 答辩日期
12. 学位授予日期
13. 底部封面日期

### 3.1 标题内容规则

第一行应将学位层级与”学位论文”组合在一起：

- 博士：`博士学位论文`
- 硕士：`硕士学位论文`

**不要**将”博士”或”硕士”单独放在”学位论文”上一行。

第二行是学位类别，只能选择一种：

- `（学术学位）`
- `（专业学位）`

不得在最终封面同时打印”学术学位/专业学位”两个选项，也不得打印斜杠作为选择符号。

官方说明图中的示例字符串带有字间空格，例如”学 术 学 位/专 业 学
位”。实际排版时应保留与样例相符的字间距；不要未经视觉核对就把所有字间距压缩成普通连续文字。

当前类别行只读取 `\xmu@type`，并在变量所在的局部分组中设置
`\xeCJKsetup{CJKglue={\hskip 0.25em}}`。调用者应将 `\degreetype` 填为
`学术学位` 或 `专业学位` 中的一种；当前代码不额外校验该变量内容。

### 3.2 内容变量

应继续使用现有模板的数据变量，不要为了排版而删除或改名：

| 内容                | 现有模板变量（如适用） |
|:--------------------|:-----------------------|
| 学校编码            | `\xmu@schoolcode`      |
| 学号                | `\xmu@idn`             |
| 博士 / 硕士         | `\xmu@level`           |
| 学术学位 / 专业学位 | `\xmu@type`            |
| 中文论文题目        | `\xmu@title`           |
| 英文论文题目        | `\xmu@entitle`         |
| 作者姓名            | `\xmu@author`          |
| 指导教师姓名        | `\xmu@advisor`         |
| 专业名称            | `\xmu@subject`         |
| 答辩日期            | `\xmu@defensedate`     |
| 学位授予日期        | `\xmu@awarddate`       |
| 封面底部日期        | `\xmu@coverdate`       |

若项目中变量名称已经调整，应以当前 `.cls` / `.tex`
中实际定义为准，不要擅自创建重复变量。

## 4. 字体与字号规范

以下字号使用 Word 中的实际磅值，同时列出中文字号名称。

| 封面元素                 | 中文字体                    | 英文字体        |    字号     | 字重 |
|:-------------------------|:----------------------------|:----------------|:-----------:|:-----|
| 学校编码、学号           | 宋体（SimSun）              | 随中文字体设置  | 小四，12 pt | 加粗 |
| 学位名称                 | 宋体（SimSun）              | —               | 二号，22 pt | 加粗 |
| 学位类别                 | 宋体（SimSun）              | —               | 二号，22 pt | 加粗 |
| 中文论文题目             | 黑体（SimHei）              | —               | 小二，18 pt | 加粗 |
| 英文论文题目             | —                           | Times New Roman | 三号，16 pt | 加粗 |
| 作者姓名                 | 楷体（KaiTi / 楷体_GB2312） | —               | 小二，18 pt | 加粗 |
| 指导教师、专业、日期信息 | 楷体（KaiTi / 楷体_GB2312） | —               | 小三，15 pt | 常规 |
| 底部日期                 | 宋体（SimSun）              | 随中文字体设置  | 四号，14 pt | 加粗 |

### 4.1 字体实现要求

1.  使用 XeLaTeX（或项目已配置的兼容中文引擎）并显式指定封面字体。
2.  不要仅依赖 `\songti`、`\heiti`、`\kaishu`
    的默认映射；必须检查这些命令在当前模板中实际映射到什么字体。
3.  中文字体目标：
    - 宋体：SimSun / 宋体
    - 黑体：SimHei / 黑体
    - 楷体：KaiTi / 楷体_GB2312
4.  英文标题必须明确使用 Times New Roman，并使用粗体字形。
5.  不得把英文标题仅设置为 `\bfseries` 而不指定 Times New Roman。
6.  不得用相似字体静默替代。若当前编译环境缺少指定字体，应在编译日志或说明中明确报告，并先解决字体问题，再进行版式微调。
7.  最终 PDF
    应检查实际嵌入或使用的字体名称，避免字体回退造成字宽和字形差异。

### 4.2 字号对应关系

| 中文字号 | 磅值  |
|:---------|:-----:|
| 小四     | 12 pt |
| 四号     | 14 pt |
| 小三     | 15 pt |
| 三号     | 16 pt |
| 小二     | 18 pt |
| 二号     | 22 pt |

### 4.3 当前字体、字号和行距实现

- 编译引擎为 XeLaTeX。`styles/common/fonts.tex` 将 `\songti`、`\heiti`、`\kaishu`
  分别映射到项目内的 `simsun.ttc`、`simhei.ttf`、`simkai.ttf`，不是依赖未检查的默认映射。
- `styles/common/base.tex` 启用 xeCJK 的 `AutoFakeBold`，中文加粗仍使用对应字体。
- 学校编码、学号和底部日期同时使用 `\fontspec[AutoFakeBold=2.17]{simsun.ttc}`，
  个人信息使用 `\fontspec{simkai.ttf}\kaishu\mdseries`，使数字与西文也采用相应字体。
- 英文标题使用 `\fontspec[BoldFont={Times New Roman Bold}]{Times New Roman}\bfseries`，
  需要系统可用的 Times New Roman 及其 Bold 字形，不设置其他字体作为替代。
- 封面局部使用 `\linespread{1}\normalfont`，排除正文 1.5 倍行距的影响。
- Word 的磅值在代码中用 `bp` 表示，即 `1 bp = 1/72 in`。字号通过
  `\fontsize{字号 bp}{行距 bp}\selectfont` 显式设置，不直接用 LaTeX 的 `pt` 代替 Word 的磅值。

| 元素 | 当前字号 | 当前行距 |
|:-----|:---------|:---------|
| 学校编码、学号 | 12 bp | 20 bp |
| 学位名称、学位类别 | 22 bp | 30 bp |
| 中文题目、作者姓名 | 18 bp | 30 bp |
| 英文题目 | 16 bp | 26 bp |
| 个人信息四行 | 15 bp | 31 bp |
| 底部日期 | 14 bp | 17 bp |

实现约束：

1.  Word 中英文标题示例实际由两个独立段落构成，不是一个自动换行的段落。
2.  LaTeX 应允许英文标题显式分行，或按两行分别排版。
3.  不要直接照搬此前模板中的 `\parbox{0.82\textwidth}`
    作为未经验证的固定宽度方案。
4.  不要完全依赖自动换行；应通过显式换行或可控的分行逻辑保持排版稳定。
5.  每一行分别水平居中。
6.  字体必须是 Times New Roman Bold，不得由默认西文字体替代。

英文标题的具体换行位置取决于论文标题长度。官方文件只提供了示例文本，没有给出适用于所有英文标题的固定最大宽度，因此不要把示例的行宽误认为学校明确规定的文本框宽度。

当前英文题目使用页面可用宽度 `146.5 mm` 的 `minipage[t]`，节点顶部为 `130.43 mm`，
行距为 `26 bp`。可以在现有 `\title` 命令的第二个参数内用 `\\` 或 `\par` 指定换行；
未显式分行时仍可在可用宽度内自动折行。两行相同字高时，第二行顶部估算约为 `139.60 mm`。

- 不使用 `tabular`、`tabularx` 等表格环境模拟这四行。

## 8. LaTeX 实现约束

以下说明对应当前 `styles/pages/cover.tex` 的 degree 分支，供后续维护时参考。

### 8.1 总体原则

1.  先保证元素内容、字体、字号、字重和相对层级正确，再做坐标微调。
2.  关键元素采用稳定的页面定位方式，避免前一个元素高度变化导致后续元素整体漂移。
3.  不要用一串 `\vspace` 和 `\vfill` 累积模拟整页布局。
4.  当前使用 TikZ `remember picture,overlay` 页面绝对定位，配合顶部锚点和 `minipage[t]`；
    必须保持页面左上角坐标与文字基线的换算关系。
5.  不要把 PDF 可见文字顶部坐标直接当成 LaTeX 基线坐标。
6.  对齐方式必须与参考文件一致：顶部信息左对齐，标题/作者/底部日期居中，个人信息左对齐。
7.  封面不显示页码。
8.  封面结束后的页码体系和正文页码逻辑应尽量保持现有模板设计，不要因重写封面而破坏。

当前命令结构为：`\maketitle` 根据 `\xmu@cover` 选择分支，degree 调用
`\xmu@degreecover`，文字布局由 `\xmu@degreecovertext{X}{Y}{宽度}{对齐命令}{内容}` 统一定位。
文字块的段首缩进和段间距均设为 `0 pt`。overlay 后的 `\null\par` 用于确保封面页实际输出，
`\restoregeometry` 恢复原页边距。公共结尾仍为 `\clearpage\pagenumbering{Roman}\zihao{-4}`。
