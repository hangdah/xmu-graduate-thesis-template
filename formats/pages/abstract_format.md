# 中英文摘要版式规范（abstract_format.md）

## 1. 适用范围

对应工程文件：

- `styles/pages/abstract-zh.tex`
- `styles/pages/abstract-en.tex`

本文件规定摘要页面结构、标题位置、正文段落、关键词和页码，不规定字体家族、字号或字体映射。

## 2. 页面组织

- 中文摘要独立成页。
- 英文摘要另起一页，紧接中文摘要之后。
- 中文摘要页在前，英文摘要页在后。
- 两个摘要页面均属于前置部分，不显示正文页眉。
- 中文摘要页码为大写罗马数字 I，英文摘要页码为 II。
- 摘要页面页码在页面底部居中。

PDF 示例中，中文摘要和英文摘要分别占据第 I、II 页。

## 3. 摘要标题

- 中文标题为“摘 要”。
- 英文标题为“Abstract”。
- 标题均水平居中。
- 标题不带章节编号。
- 标题位于页面上方正文区域，标题与摘要正文之间保留明显间距。
- Word 的“我的标题”样式设置了分页前换页、居中、固定行距 36 pt、段后间距 24 pt；其版面效果应由统一标题样式实现，不要通过在摘要正文中添加大量空行模拟。

## 4. 摘要正文

- 中文摘要正文采用普通正文段落的排版逻辑。
- 英文摘要正文采用普通英文段落的排版逻辑。
- 段落两端对齐。
- 行距为 1.5 倍。
- 首行缩进约两个字符宽度；英文摘要的 PDF 示例也表现为首行缩进。
- 正文段落自然换行，不使用手工换行控制每一行的长度。
- 摘要正文与关键词之间保留清晰的段落间隔。

## 5. 关键词

### 5.1 中文关键词

- 位于中文摘要正文之后。
- 标签使用“关键词：”。
- 标签与关键词内容在同一段落中。
- 多个关键词之间使用中文分号 `；` 分隔。
- 标签与关键词内容应在同一行开始；内容过长时允许自然换行。
- PDF 示例中关键词段落的起始位置与正文首行缩进接近。

### 5.2 英文关键词

- 位于英文摘要正文之后。
- 标签使用 `Keywords:`。
- 标签与关键词内容在同一段落中。
- 多个关键词之间使用英文分号 `;` 分隔。
- 内容过长时允许自然换行，不要通过缩小页面或压缩字距强行放在一行。

## 6. 内容接口

继续使用当前工程的摘要环境和关键词命令：

- `abstract` 环境承载中文摘要。
- `enabstract` 环境承载英文摘要。
- `\keywords{中文关键词}{English Keywords}` 的两个参数分别提供中英文关键词。

不要把摘要正文硬编码到样式文件中；样式文件只负责排版。

## 7. LaTeX 实现要求

- 中英文摘要分别使用独立环境和独立页面。
- 统一管理标题、正文和关键词之间的间距。
- 摘要页不显示正文奇偶页页眉。
- 摘要页使用罗马数字页码，并与后续目录页连续。
- 不要让摘要页码与正文页码共用同一个计数起点。

## 8. 验收清单

- [ ] 中文摘要单独一页。
- [ ] 英文摘要单独一页。
- [ ] 中文摘要在前，英文摘要在后。
- [ ] 两个标题分别居中且无章节编号。
- [ ] 正文行距为 1.5 倍，首行缩进约两个字符。
- [ ] 中文关键词使用“关键词：”和中文分号。
- [ ] 英文关键词使用 `Keywords:` 和英文分号。
- [ ] 摘要页不显示正文页眉。
- [ ] 页码分别为 I、II，且底部居中。
