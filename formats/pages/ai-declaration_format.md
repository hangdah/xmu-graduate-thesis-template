### 1.2 分析依据与方法

- DOCX：检查 `word/document.xml`、`word/styles.xml`、`word/settings.xml`、`word/fontTable.xml`、字体关系文件及页面节属性。
- PDF：使用 PDF 文本块/文字 span 坐标提取，并将页面渲染为图片逐页核对。
- 页面坐标：统一采用页面左上角为原点，X 向右、Y 向下，单位为 mm。
- PDF 坐标来自 PDF 文本 span 的边界框，换算关系为 `1 pt = 25.4 / 72 mm`。坐标四舍五入到 0.1 mm。它们是 PDF 文本边界框，不等同于逐个字形黑色像素的精确轮廓。

## 2. 页面整体设置

### 2.1 页面尺寸与方向

### 2.3 分节、页眉与页脚

- 每个 DOCX 均只有一个 `w:sectPr`，即一个页面节。
- 每份文件均为单栏布局。
- DOCX 中没有实际页眉、页脚内容。
- PDF 中没有页眉、页脚或页码。
- 页眉距边界和页脚距边界虽然在 DOCX 中有数值，但由于没有对应内容，不应额外生成页眉、页脚或页码。
- 未发现显式分页符或分节分页符。

### 4.4 字体属性与异常项

1.  正文和标题均未发现显式斜体、下划线或独立粗体设置。
2.  第 1、2、3 节标题使用的是”黑体”字体本身，不应把它误判为”仿宋加粗”。
3.  PDF 正文文字 span 的字号约为 15.96 pt，与 DOCX 明确设置的 16 pt 一致；PDF 中的微小差值属于 PDF 字体度量/提取结果，不应把 DOCX 字号改成 15.96 pt。
4.  **Used 版本”具体用途”示例首部存在源文件格式异常：**
    - DOCX 该段落首个 run 为两个空格加左括号 `（`，该 run 没有直接设置字体和字号。
    - 后续示例文字直接设置为 16 pt 仿宋。
    - PDF 中该左括号以约 10.56 pt 的 SimSun 字体呈现，而后续文字约为 15.96 pt FangSong。
    - 这是 DOCX 源文件真实存在的 run 格式差异，不应擅自把它描述成整段 16 pt 仿宋。
    - LaTeX 实现时建议先确认是否需要逐字复刻这一异常。若以整体视觉统一为目标，可将括号统一为 16 pt 仿宋，但这属于规范化处理，不是对源文件的原样复刻。

### 4.5 样式继承注意事项

两份 DOCX 的 Normal 样式默认字体为 Calibri（西文）/宋体（东亚），字号默认值为 10.5 pt；但实际声明文字均有直接字体和字号设置，应以各 run 的直接格式为准。

Unused 版本标题后的空段落没有直接设置字体、字号和行距，不能把 Normal 样式的默认值误写成正文格式。

## 9. 特殊排版规则与 DOCX/PDF 交叉验证

### 9.1 Used 与 Unused 的关键差异

| 对比项         | Used                             | Unused                 |
|:---------------|:---------------------------------|:-----------------------|
| 标题第二行     | 使用人工智能工具声明             | 未使用人工智能工具声明 |
| 标题后结构     | 标题后直接进入引导段落           | 标题后有两个空段落     |
| 正文结构       | 引导段 + 三节内容                | 两段声明正文           |
| 正文字号       | 16 pt                            | 16 pt                  |
| 正文字体       | 仿宋；节标题黑体；标签楷体       | 仿宋                   |
| 正文固定行距   | 26 pt                            | 28 pt                  |
| 正文首行缩进   | 通常 32 pt；具体用途示例为 21 pt | 32 pt                  |
| 正文起始 PDF Y | 49.9 mm                          | 61.5 mm                |
| 页面下边距     | 19.40 mm                         | 25.40 mm               |
| 签名/日期行距  | 28 pt                            | 28 pt                  |

### 9.2 DOCX 与 PDF 一致的内容

- 两份文件的 A4 页面尺寸、纵向方向、左右边距和上边距一致。
- 两行标题的 PDF 垂直位置一致。
- 标题字体、字号、正文主要字体和字号均能在 DOCX 中找到明确设置。
- 正文行距与 PDF 实测的行间基线距离吻合：Used 约 9.2 mm，Unused 约 9.9 mm。
- 正文首行位置与 DOCX 的 640 twips 首行缩进吻合。
- 签名、日期均表现为普通文字段落，不存在表格边框或图形对象。

### 9.3 已发现的差异与异常

1.  **页面下边距不同：** Used 为 19.40 mm，Unused 为 25.40 mm。属于 DOCX 原始页面设置差异，不是 PDF 测量误差。
2.  **正文行距不同：** Used 为 26 pt，Unused 为 28 pt。PDF 行间距测量支持这一差异。
3.  **标题后留白不同：** Unused 有两个空段落，正文在 PDF 中明显下移；Used 没有对应空段落。
4.  **Used 具体用途示例首括号字号异常：** DOCX run 缺少直接字体/字号设置，PDF 将其呈现为约 10.56 pt SimSun，而相邻文字为约 16 pt FangSong。
5.  **标题字体的 PDF 内部名称：** PDF 使用嵌入子集字体名称，不能单独从子集名称判断字体家族；DOCX 明确记录为方正小标宋简体，因此以 DOCX 为准。
6.  **Used 页面底部坐标：** PDF 最后日期文字 span 底部约 Y=276.1 mm，页面底部剩余约 20.9 mm；DOCX 下边距为 19.40 mm。两者测量对象不同（段落布局边界与 PDF 字符 span 边界框），不能直接认定为格式冲突。

### 9.4 是否需要人工确认

建议人工确认的唯一明显异常是：是否需要保留 Used 版本”具体用途”示例首括号约 10.56 pt 的小字号，还是在 LaTeX 中统一为 16 pt 仿宋。

除此之外，页面尺寸、主要字体字号、段落结构、行距、边距差异均有 DOCX 或 PDF 证据支持。

## 10. LaTeX 实现要求

以下内容是给 Codex 的实现指导，不是对 LaTeX 源码的直接修改。

### 10.1 总体实现原则

- 使用 XeLaTeX。
- 两个版本分别实现为独立命令、环境或条件分支。
- 可共用标题字体、正文基础字体和签名日期模块，但必须保留版本特有的页面下边距、正文行距、正文起始位置和段落结构。
- 以普通段落排版为主，不要将所有文字转成绝对定位对象。
- 不要使用表格模拟原 DOCX 中不存在的表格。
- 不要将 Used 的三节结构误用于 Unused 版本。

### 10.2 字体配置建议

建议在模板中定义独立字体命令，避免在正文中重复硬编码字体名称：

``` latex
% 以下仅为字体配置示意，需确保对应字体已安装
\newCJKfontfamily\XMUDeclarationTitle{方正小标宋简体}
\newCJKfontfamily\XMUDeclarationFangSong{仿宋}
\newCJKfontfamily\XMUDeclarationHei{黑体}
\newCJKfontfamily\XMUDeclarationKai{楷体}
```

对应关系：

- 标题两行：方正小标宋简体，18 pt。
- 普通正文：仿宋，16 pt。
- Used 版本的节标题：黑体，16 pt。
- Used 版本的”工具名称：““具体用途：”：楷体，16 pt。
- 签名和日期：仿宋，16 pt。

如果系统中没有对应字体，应明确报告字体缺失，不要静默替换为宋体、微软雅黑或其他字体。

### 10.3 页面设置建议

建议为两个版本分别设置页面参数：

``` latex
% A4 纸张尺寸在文档类或全局 geometry 设置中声明一次
\geometry{a4paper}

% Used：使用人工智能工具声明
\newgeometry{
  top=25.4mm,
  bottom=19.4mm,
  left=31.75mm,
  right=31.75mm
}

% Unused：未使用人工智能工具声明
\newgeometry{
  top=25.4mm,
  bottom=25.4mm,
  left=31.75mm,
  right=31.75mm
}
```

以上为页面边距参数示意。若模板已有统一 geometry 管理机制，应在该机制中实现两个版本的局部覆盖，避免重复加载或冲突设置。

页眉、页脚均不需要输出。

### 10.4 正文行距和缩进建议

Used：

``` latex
\fontsize{16pt}{26pt}\selectfont
\setlength{\parindent}{32pt}
```

Unused：

``` latex
\fontsize{16pt}{28pt}\selectfont
\setlength{\parindent}{32pt}
```

签名和日期均使用 16 pt 字号、28 pt 行距。

Used 版本”具体用途”示例段落需要单独处理 21 pt 首行缩进。不要因为这一段与其他正文不同，就修改全局 `\parindent`。

段落两端对齐；标题和签名日期段落居中。

### 10.5 段落间距建议

Used：

- 引导段落后增加 7.85 pt 段后间距。
- 第 2 节标题前增加 7.85 pt 段前间距。
- 第 3 节标题前增加 7.85 pt 段前间距。
- 其他段落不额外增加统一段间距。

Unused：

- 标题第二行之后保留与 PDF 视觉效果一致的留白。
- DOCX 中该位置由两个空段落形成；LaTeX 可以用可控垂直间距复现，但应以 PDF 中正文首行 Y≈61.5 mm 为验收目标。
- 不要将 Used 版本的正文起始位置直接套用到 Unused。

### 10.6 标题与签名日期区域

标题：

- 两行均居中。
- 字号 18 pt，方正小标宋简体。
- 第一行 PDF 文字 span 顶部约 Y=27.2 mm。
- 第二行 PDF 文字 span 顶部约 Y=38.2 mm。
- 两行标题的垂直位置在两个版本中一致。

签名与日期：

- 原始 DOCX 采用居中段落，并在文字前放置多个空格。
- LaTeX 中不建议直接用大量普通空格复刻，因为空格宽度、字体和排版环境会影响位置。
- 建议使用一个无边框的局部文本块或固定水平偏移，令可见文字起始位置接近 X=114–116 mm。
- 签名与日期保持两行，行距 28 pt。
- 日期文字必须保留为 `日期：____年__月__日`。
- 原文件没有签名横线，不要擅自添加横线或表格边框。

### 10.7 内容与分页

- Used 和 Unused 各自应保持一页。
- 不添加页码。
- 不添加页眉、页脚。
- 不添加学校 Logo、印章、表格或装饰线。
- 不擅自改写官方声明正文。
- 不要为了让两种版本高度一致而改动原始行距、边距或留白。
