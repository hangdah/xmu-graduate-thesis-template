# 参考文献版式规范（references_format.md）

## 1. 适用范围

对应工程文件：

- `styles/pages/references.tex`
- 根目录参考文献样式文件，例如 `gbt7714-2005.bst`
- 根目录 `references.bib`

本文件规定参考文献页面、标题、编号和条目布局，不规定字体家族或字号。

## 2. 页面与标题

- 参考文献从新页开始。
- 标题为“参考文献”。
- 标题居中，不带正文的章节编号。
- 参考文献页使用正文的阿拉伯数字页码，且与正文连续。
- 参考文献页参与正文奇偶页页眉规则：奇数页页眉显示“参考文献”，偶数页页眉显示论文题目。
- 页眉下方有横线，页码底部居中。

官方 PDF 中参考文献位于独立页面，标题居中；该页页码为 3，页眉显示“参考文献”。

## 3. 条目编号

官方 PDF 示例使用数字顺序编号：

```text
[1] ...
[2] ...
[3] ...
```

要求：

- 每条参考文献有独立编号。
- 编号使用方括号。
- 编号由参考文献系统自动生成。
- 正文引用和文后条目编号应一致。
- 不要在 `.bib` 条目内容中手工写入 `[1]` 等编号。

## 4. 条目内容结构

官方 PDF 的示例条目体现出以下信息组织方式：

- 作者；
- 出版年份；
- 文献题名；
- 文献类型标识，例如 `[J]`；
- 期刊名称；
- 期号、卷期信息；
- 起止页码。

例如官方示例中可见类似结构：

```text
[1] 作者. 2008. 题名[J]. 期刊名称,(03): 6-10.
```

本次材料主要展示中文期刊文献，没有提供足够样本来完整确认所有文献类型（学位论文、专著、会议论文、网页等）的细节格式。不要仅凭一个期刊条目自行推导所有类型的完整著录规则。

## 5. 条目段落与缩进

Word 的“文献列表”样式将左缩进和首行缩进覆盖为 0；PDF 示例中的条目从同一左边界开始，换行后也没有明显的悬挂缩进。

因此：

- 参考文献条目左对齐。
- 不使用正文的两字符首行缩进。
- 不额外添加悬挂缩进，除非当前工程或学校其他明确规范要求。
- 条目之间保持紧凑排列。
- Word 样式没有明确设置条目段前、段后间距和固定行距；PDF 视觉上也较紧凑。因此不要将参考文献强制设置为正文的 1.5 倍行距或添加大段间距。

## 6. BibTeX 与样式文件

当前工程 README 已说明：

- `styles/pages/references.tex` 负责参考文献环境、页眉页脚、目录条目和条目间距。
- 根目录 `gbt7714-2005.bst` 控制作者、题名、年份等字段的输出顺序。
- `references.bib` 存放实际文献数据。

开源 `example.tex` 也明确说明其 BibTeX 参考文献样式采用 GB/T 7714-2005。

因此 Codex 应：

1. 优先保留当前工程已经使用的 `gbt7714-2005.bst`。
2. 不要为了模仿单条 PDF 示例而随意修改 `.bst` 的字段顺序。
3. 先检查当前 `.bst` 输出是否已经符合数字顺序编码和现有参考文献结构。
4. 通过 `\bibfont`、`\bibsep` 等已有接口调整条目排版；本次不处理字体参数。
5. 避免同时输出 BibTeX 生成列表和手工 `thebibliography` 列表。

## 7. 目录与页眉

- 参考文献标题应进入中文目录。
- 如当前工程支持英文目录，也应按现有双语目录机制处理；官方 PDF 只展示了中文“参考文献”条目，没有明确给出英文目录中的参考文献译名，不要自行强制翻译。
- 参考文献作为独立部分，需要更新奇数页页眉标记。

## 8. LaTeX 实现要求

- 继续使用当前工程的 `reference` 环境。
- 参考文献标题采用无编号独立章节。
- 参考文献条目由 BibTeX 统一生成。
- 不要手工固定参考文献页码。
- 修改后至少执行完整的 XeLaTeX/BibTeX 编译流程，检查引用编号、文献列表和目录页码。

## 9. 验收清单

- [ ] 参考文献独立起页。
- [ ] 标题居中且无正文章编号。
- [ ] 条目采用 `[1]`、`[2]` 数字编号。
- [ ] 正文引用编号与文后编号一致。
- [ ] 条目左对齐，不继承正文首行缩进。
- [ ] 条目紧凑排列，不强制使用正文 1.5 倍行距。
- [ ] 参考文献页码与正文连续。
- [ ] 奇数页页眉显示“参考文献”。
- [ ] BibTeX 只生成一份文献列表。
