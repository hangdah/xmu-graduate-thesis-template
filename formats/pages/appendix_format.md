# 附录版式规范（appendix_format.md）

## 1. 适用范围

对应工程文件：`styles/pages/appendix.tex`。

**重要：本次官方研究生 Word/PDF 样例没有附录页面。** 本文件中的附录编号规则主要来自开源 `example.tex`，属于实现参考，不能视为已经由研究生官方 PDF 验证的完整规范。

## 2. 附录位置

开源 `example.tex` 的示例顺序为：

1. 正文；
2. 参考文献；
3. 附录；
4. 致谢。

官方研究生 PDF 示例没有附录，实际顺序为参考文献之后直接进入致谢。

因此：

- 如果当前 `main.tex` 已经定义附录位置，Codex 不要擅自改变用户的内容顺序。
- 如果论文包含附录，可参考开源模板将附录放在参考文献之后、致谢之前。
- 如果论文不包含附录，不要生成空白附录页。

## 3. 附录编号

开源 `example.tex` 明确说明：附录中的编号均以字母 A 开头。

建议按当前工程既有机制检查以下编号是否带有 A 前缀：

- 附录章节/节；
- 附录中的图；
- 附录中的表；
- 附录中的公式。

例如可采用 `A.1`、`A.2` 等形式。附录图表公式应与正文计数器分开，不能继续沿用正文的章节编号。

本次材料没有附录 PDF 页面，无法确认学校要求的附录标题具体文字、标题间距、页眉内容、页码特殊规则或是否要求多个附录使用 A、B、C 分组。不要自行扩展这些规则。

## 4. 标题层级

开源 `example.tex` 展示了：

- `\begin{appendix} ... \end{appendix}`；
- `\xmusection{中文标题}{English Title}`；
- `\xmusubsection{中文标题}{English Title}`；
- `\subsubsection{第四级标题}`。

这说明附录可继续复用正文的多级标题命令和双语目录写入机制，但编号需要切换为附录编号体系。

## 5. 图、表、公式

- 附录中的图、表、公式应使用独立的附录编号体系。
- 建议编号以 A 开头，例如图 A.1、表 A.1、公式 (A.1)。
- 这是开源模板注释所指向的编号逻辑，最终格式仍需结合当前工程和学校其他正式要求确认。
- 图题、表题、公式主体的版式继续复用 `../common/figures_tables_format.md` 和 `../common/equations_format.md`，不要在附录中复制另一套完全不同的样式。

## 6. 页眉、页码与目录

本次官方研究生 PDF 没有附录页，因此以下项目无法从官方样例确认：

- 附录页眉究竟显示“附录”还是具体附录标题；
- 附录页码是否与正文连续；
- 多个附录是否分别另起奇数页；
- 附录目录标题的具体层级和翻译方式。

开源模板的本科规范说明正文、参考文献、附录使用阿拉伯数字连续页码。当前研究生模板可先沿用全局页面规范中的连续阿拉伯数字页码，但 Codex 应检查当前工程是否已经如此设置，不要重复重置页码。

## 7. LaTeX 实现要求

- 保留当前 `appendix` 环境。
- 检查进入附录时是否正确切换章节、图、表、公式计数器。
- 不要影响正文编号。
- 附录结束后应正确恢复后续致谢等部分的页眉和编号逻辑。
- 没有证据的标题间距、字体、页眉内容等暂时保持现状。

## 8. 验收清单

- [ ] 有附录时才生成附录部分。
- [ ] 附录编号以 A 开头。
- [ ] 附录图、表、公式与正文编号分离。
- [ ] 附录标题能正常写入目录。
- [ ] 附录不影响正文及后续部分的页码连续性。
- [ ] 未擅自添加官方材料未明确要求的附录样式。
